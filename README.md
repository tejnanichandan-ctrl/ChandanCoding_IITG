Coursework and practice from the **DA108** course (IIT Guwahati) — from Python basics through NumPy, OOP, exploratory data analysis and linear regression.

---

## What's inside

| Folder / file | Topic |
|---|---|
| `linear_regression_lab/` | Linear regression notebook, plus cost, revenue and profit-maximisation / shutdown curves (300 DPI charts) |
| `DA108_Lab08/` | Sales analysis on an India sales dataset — dataset creation, analysis and visualisation scripts |
| `eda.ipynb` | Exploratory data analysis |
| `numpy.ipynb`, `stringandnumpy.ipynb` | NumPy arrays and string handling |
| `DA108_week8_OOP_practice.ipynb` | Object-oriented programming in Python |
| `DA108_Week7.ipynb`, `funweeksix.ipynb`, `loop.ipynb` | Weekly exercises — functions, loops and control flow |
| `palindrome.py`, `Area.py`, `example.py` | Small Python programs |
| `students.csv`, `student.json`, `*.txt` | Sample data for file-handling exercises |
